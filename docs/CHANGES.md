# Изменённые файлы

| Файл | Изменение |
|---|---|
| `bot.py` | Существующие Telegram-сценарии, навигация/консультация, безопасное подтверждение, права CRM, статистика, доставка и напоминания. Импорты прежних DB-помощников сохранены для совместимости. |
| `run.py` | Запуск через проверенную конфигурацию и блокировку процесса; `--check-config`. |
| `config.py` (новый) | Файл/окружение, типизированная конфигурация, валидация, фильтр журналов. |
| `database.py` (новый) | Вынесенные существующие SQLite-функции, миграции/backup, FSM, идемпотентность, источники, аналитика и явное обезличивание. |
| `runtime.py` (новый) | OS-блокировка одного процесса на базу для POSIX/Windows. |
| `exports.py` (новый) | Общая защита CSV и приватная атомарная запись без случайной замены. |
| `export_leads.py` | Read-only база, совместимые основные столбцы и новые поля, явная перезапись только по флагу. |
| `maintenance.py` (новый) | Резервирование/миграция/обработка приватности при остановленном боте. |
| `tariffs.py` | Загрузчик/проверка данных, клавиатуры, отображение региона/актуальности. |
| `tariff_data.json` (новый) | Исходные 30 предложений и пять категорий без новых цен; поля региона, проверки, актуальности и условий. |
| `requirements.txt` | aiogram с поддержкой прокси, закреплённая проверенная версия, tzdata для Windows. |
| `requirements-lock.txt` (новый) | Закреплённые версии транзитивных зависимостей. |
| `.gitignore` | Защита SQLite/WAL/выгрузок/резервных копий/локальных артефактов. |
| `bot.env.example` (новый) | Полный образец настроек без токенов/ПДн. |
| `tests/test_bot.py` (новый) | 29 тестов, временные базы, имитация Telegram API. |
| `README.md` (новый) | Windows/Linux, настройки, сценарии, CRM, тарифы, источники и защита данных. |
| `docs/AUDIT.md` (новый) | Подтверждённые проблемы с исходными строками и приоритетами. |
| `docs/UPDATE.md` (новый) | Безопасное обновление и ограничения отката. |
| `docs/VALIDATION.md` (новый) | Реальные результаты и непроверенные возможности. |
| `docs/FUTURE.md` (новый) | Отложенные улучшения. |
